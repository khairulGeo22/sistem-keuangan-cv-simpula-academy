# CV. Simpul Project Academy - Order Artikel

Aplikasi web lokal untuk mengelola order artikel, invoice, pembayaran, kas project, dan rekap bulanan.

Kontak admin:

- WhatsApp: 085262608383
- Email: aroelcendekia@gmail.com

## Cara Pakai

1. Buka `index.html` di browser.
2. Klik **Masuk aplikasi**.
3. Catat order, transaksi kas, invoice, dan rekap.
4. Gunakan tombol **Backup** secara berkala agar data aman.

## Form Order Publik

Gunakan `order-form.html` sebagai halaman yang dibagikan ke calon customer.

Alurnya:

1. Customer mengisi data order.
2. Customer klik **Kirim via WhatsApp**.
3. Admin menerima format order rapi di WhatsApp.
4. Admin memasukkan order ke aplikasi utama.

Form publik sudah memuat checklist brief, target kata, gaya bahasa, target pembaca, keyword, referensi, budget, dan persetujuan ketentuan.

## Template WhatsApp Admin

Di menu **Invoice**, admin bisa memilih template pesan untuk:

- Order diterima
- Invoice dikirim
- Pengingat pembayaran
- Pekerjaan selesai
- Revisi diterima

## Catatan

- Aplikasi tetap bisa berjalan tanpa internet.
- Data tersimpan di browser lokal pengguna.
- Untuk mencetak invoice, buka menu **Invoice**, pilih invoice, lalu klik **Cetak invoice**.
